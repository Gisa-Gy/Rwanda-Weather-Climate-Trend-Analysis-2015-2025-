Rwanda Weather & Climate Trend Analysis (2015 → 2025)

A step-by-step research workflow for analysing a decade of rainfall and temperature across Rwanda using Google Earth Engine, then bringing those layers into QGIS through the Google Earth Engine plugin — from Code Editor setup to a published web app and a styled desktop map.

Platform: GEE Code Editor (JavaScript) + QGIS Rainfall: CHIRPS Pentad · ~5.5 km Temperature: ERA5-Land Monthly · ~11 km Period: 2015–2025 (11 years) Output: Trend maps, charts, Web App, QGIS layers

This session teaches a temporal trend-analysis workflow — the core method for studying how climate variables change over time. We build an annual time series of total rainfall and mean temperature for every year from 2015 to 2025, map the deviation of each year from the decade average (anomaly), fit a per-pixel linear trend to see where the climate is getting wetter, drier, warmer or cooler, and deliver the result as both an interactive Earth Engine web app and a set of GeoTIFFs styled in QGIS.

What you will build: annual rainfall totals (2015–2025), a decade-mean rainfall map, a rainfall anomaly map for any chosen year, a mean-temperature series, per-pixel trend (slope) maps for rainfall and temperature, time-series charts averaged over Rwanda, an exported GeoTIFF stack, a published app titled "Rwanda Climate Trends Explorer", and the same layers loaded and symbolised inside QGIS.
Academic honesty note: This guide gives you the complete method and reproducible code. It does not pre-fill result numbers (e.g. "rainfall rose by X mm"). You generate the real figures by running the scripts on live data, then report what you actually observe. Every value in your final write-up must come from your own Console output and charts.

DBDatasets Used

Both archives are free, global, and hosted in the Earth Engine Data Catalog — no download needed to analyse them.

VariableDataset IDResolutionBandUnits
Rainfall UCSB-CHG/CHIRPS/PENTAD ~5.5 km (0.05°) precipitation mm per pentad
Temperature ECMWF/ERA5_LAND/MONTHLY_AGGR ~11 km (0.1°) temperature_2m Kelvin (→ °C)
Why CHIRPS Pentad: CHIRPS blends satellite rainfall estimates with station data and is the standard archive for rainfall studies in East Africa. A "pentad" is a 5-day period, so there are 72 pentads per year. Summing them gives an accurate annual rainfall total. Prefer pentad over daily unless you specifically need daily resolution — it is lighter and less noisy.
Why ERA5-Land Monthly: ERA5-Land is ECMWF's reanalysis of land-surface climate. The monthly-aggregated collection gives one temperature_2m value per month. Values are in Kelvin — subtract 273.15 to convert to degrees Celsius.

3Load & Filter CHIRPS Rainfall

CHIRPS Pentad gives rainfall in millimetres for every 5-day period. We load the collection and filter it to the full 2015–2025 study period.

Load CHIRPS rainfall
// CHIRPS pentad rainfall (mm per 5-day period)
var chirps = ee.ImageCollection('UCSB-CHG/CHIRPS/PENTAD')
  .select('precipitation')
  .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01')
  .filterBounds(aoi);

print('CHIRPS pentad images loaded:', chirps.size());
Why: filterDate keeps only pentads inside the study decade (note the end date is exclusive, so we pass 2026-01-01 to include all of 2025). filterBounds keeps images intersecting Rwanda. You should see roughly 72 × 11 ≈ 792 pentad images in the Console.

4Build Annual Rainfall Totals

To study year-to-year change we collapse the 72 pentads of each year into one annual total rainfall image. We map over the list of years and sum each year's pentads.

Annual rainfall total collection
// For each year, sum all pentads -> one total-rainfall image
var annualRain = ee.ImageCollection.fromImages(
  years.map(function(y){
    y = ee.Number(y);
    var start = ee.Date.fromYMD(y, 1, 1);
    var end   = start.advance(1, 'year');
    var total = chirps.filterDate(start, end).sum()
                  .clip(aoi)
                  .rename('rain');
    return total.set({
      'year': y,
      'system:time_start': start.millis()
    });
  })
);

// Decade-average rainfall (mean of the annual totals)
var rainMean = annualRain.mean().rename('rain_mean');

var rainVis = {min: 800, max: 1600,
  palette: ['#ffffcc','#a1dab4','#41b6c4','#2c7fb8','#253494']};

Map.addLayer(rainMean, rainVis, 'Mean Annual Rainfall 2015-2025');
Set your own min/max: The palette range 800–1600 mm is a starting guess for Rwanda. After the layer loads, open the Inspector, click a few pixels to read real totals, and adjust min/max so the colours span your actual data — never leave a range that clips everything to one colour.

5Load ERA5-Land Temperature

Now the temperature side. ERA5-Land Monthly gives one temperature_2m value per month in Kelvin. We build an annual mean temperature image for each year, converted to Celsius.

Annual mean temperature (°C)
// ERA5-Land monthly 2 m air temperature (Kelvin)
var era5 = ee.ImageCollection('ECMWF/ERA5_LAND/MONTHLY_AGGR')
  .select('temperature_2m')
  .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01');

// For each year: mean of 12 months, K -> C
var annualTemp = ee.ImageCollection.fromImages(
  years.map(function(y){
    y = ee.Number(y);
    var start = ee.Date.fromYMD(y, 1, 1);
    var end   = start.advance(1, 'year');
    var meanK = era5.filterDate(start, end).mean();
    var meanC = meanK.subtract(273.15).clip(aoi).rename('temp');
    return meanC.set({
      'year': y,
      'system:time_start': start.millis()
    });
  })
);

var tempMean = annualTemp.mean().rename('temp_mean');

var tempVis = {min: 15, max: 24,
  palette: ['#2c7bb6','#abd9e9','#ffffbf','#fdae61','#d7191c']};

Map.addLayer(tempMean, tempVis, 'Mean Annual Temp 2015-2025 (C)', false);
Why subtract 273.15: Reanalysis temperature is stored in Kelvin. Converting to Celsius makes the map and charts readable. Rwanda's highland climate means values are cooler than you might expect for an equatorial country — the palette range 15–24 °C is a reasonable start; refine it with the Inspector.

6Map a Rainfall Anomaly (Wet / Dry Years)

An anomaly answers RQ2: how did one year compare to the decade average? Positive = wetter than normal, negative = drier. We pick a year, subtract the mean, and map it on a diverging palette.

Rainfall anomaly for a chosen year
// Choose the year to inspect (change this number)
var targetYear = 2023;

var yearImg = ee.Image(
  annualRain.filter(ee.Filter.eq('year', targetYear)).first()
);

// Anomaly = that year's total - decade mean
var rainAnomaly = yearImg.subtract(rainMean).rename('rain_anom');

var anomVis = {min: -400, max: 400,
  palette: ['#8c510a','#d8b365','#f6f6f6','#5ab4ac','#01665e']};
  // brown = drier than normal, teal = wetter than normal

Map.addLayer(rainAnomaly, anomVis,
  'Rainfall Anomaly ' + targetYear);
Inspect it: Switch on the Inspector and click pixels to read the anomaly in millimetres. Change targetYear and re-run to compare different years. Brown areas received less rain than the decade norm; teal areas received more.

7Time-Series Trend Charts

Charts answer RQ1 and RQ4 directly: they show the whole-country average for every year. We build one rainfall chart and one temperature chart, each averaging over Rwanda.

Annual rainfall & temperature charts

var rainChart = ui.Chart.image.series({
  imageCollection: annualRain,

  reducer: ee.Reducer.mean(),

    hAxis: {title: 'Year', format: '####'},
    vAxis: {title: 'Rainfall (mm/year)'},
    colors: ['#2c7fb8'], legend: {position: 'none'}
  });
print(rainChart);

// --- Temperature: mean C per year, averaged over Rwanda ---

8Per-Pixel Linear Trend (Slope)

This answers RQ3: where is Rwanda getting wetter, drier, warmer or cooler? We fit a straight line (rainfall or temperature vs year) in every pixel and map the slope. Positive slope = increasing over time.

Linear slope of rainfall & temperature
// Add a 'year' band to each image so we can regress against it
var addYearBand = function(img){
  var yr = ee.Number(img.get('year'));
  var yearBand = ee.Image.constant(yr).toFloat().rename('year');
  return img.addBands(yearBand);
};

// Rainfall trend: slope of rain vs year (mm per year)
var rainWithYear = annualRain.map(addYearBand)
  .select(['year', 'rain']);
var rainTrend = rainWithYear.reduce(ee.Reducer.linearFit())
  .select('scale').rename('rain_slope').clip(aoi);

// Temperature trend: slope of temp vs year (C per year)
var tempWithYear = annualTemp.map(addYearBand)
  .select(['year', 'temp']);
var tempTrend = tempWithYear.reduce(ee.Reducer.linearFit())
  .select('scale').rename('temp_slope').clip(aoi);

var rainTrendVis = {min: -30, max: 30,
  palette: ['#8c510a','#f6f6f6','#01665e']};
var tempTrendVis = {min: -0.1, max: 0.1,
  palette: ['#2c7bb6','#f6f6f6','#d7191c']};

Map.addLayer(rainTrend, rainTrendVis, 'Rainfall Trend (mm/yr)', false);
Map.addLayer(tempTrend, tempTrendVis, 'Temperature Trend (C/yr)', false);
Interpret slope carefully: linearFit returns a scale band (the slope) and an offset band (the intercept). A slope of +20 mm/yr means rainfall rose ~20 mm each year on average over the decade. With only 11 data points, treat slopes as indicative, not statistically definitive — a decade is short for climate trend detection. Say so in your write-up.

12Install the Google Earth Engine Plugin in QGIS QGIS

To use Earth Engine inside QGIS you install a plugin that connects your Google account to the desktop. This lets you add GEE layers directly to a QGIS project and export them as GeoTIFFs — the workflow shown in the reference video.

Click by click
  1. Open QGIS. Go to the Plugins menu → Manage and Install Plugins…
  2. In the search box, type Google Earth Engine.
  3. Select the Google Earth Engine plugin in the list and click Install Plugin.
  4. Wait for the message "Plugin installed successfully", then close the dialog.
  5. The plugin now appears under the Plugins menu as Google Earth Engine.
Requirement: The plugin needs Python and the earthengine-api in QGIS's Python environment. Recent QGIS builds handle this for you; if the plugin reports a missing module, install it from the OSGeo4W Shell (Windows) or your QGIS Python with pip install earthengine-api, then restart QGIS.

14Add Your Climate Layers in QGIS QGIS

There are two ways to get your analysis into QGIS: (A) render a live GEE layer through the plugin, or (B) load the GeoTIFFs you exported in Step 9. Option B is more reliable for a report because the data is local.

Option A — Live GEE layer via the plugin

The plugin exposes GEE tools in the Processing Toolbox. You can add an Earth Engine image by its ID and an extent — the same "Add image" tool shown in the reference video.

Click by click
  1. Open Processing → Toolbox. Expand the Google Earth Engine group (identical to the Plugins-menu tools).
  2. Double-click Add image.
  3. In Image ID, paste a valid Earth Engine image ID. To render your own mean-rainfall result live, first export it to an Earth Engine asset (Export.image.toAsset) and use that asset ID here.
  4. Set the extent — click Map Canvas Extent to use the current view over Rwanda.
  5. Choose a band and a colour ramp (or leave blank), then click Run.
  6. The tiled layer streams from the Earth Engine server and appears on the QGIS canvas. It may take a moment to draw.
Single-band palette rule: If you pass a multi-band image with a palette, GEE returns an error like "cannot provide a palette when visualizing more than one band." Select just one band (or map the same band to R, G and B) before running — your trend and mean layers are single-band, so they display cleanly.

Option B — Load the exported GeoTIFFs Recommended for reports

Click by click
  1. Download the three GeoTIFFs from your Google Drive earthengine folder to your computer.
  2. In QGIS, open the Browser panel, navigate to the folder, and drag each .tif onto the map — or use Layer → Add Layer → Add Raster Layer.
  3. The rasters load already in EPSG:32735 (the CRS you exported). QGIS reprojects on the fly if your project CRS differs.
  4. Remove any temporary live tile layer so only your final rasters remain.

15Style & Finish the Map in QGIS QGIS

A live GEE tile layer can't be re-symbolised in QGIS — but your exported GeoTIFFs can. Apply a proper colour ramp so the map is publication-ready, exactly as in the reference workflow.

Click by click
  1. Right-click the raster → Properties → Symbology.
  2. Set Render type to Singleband pseudocolor.
  3. Choose an interpolation and Mode → Equal Interval (or Quantile), then set the class count.
  4. For rainfall totals, pick a sequential ramp (e.g. Blues); for the trend slope, pick a diverging ramp (e.g. RdBu) so negative and positive stand apart. You can Invert a ramp or use Turbo if preferred.
  5. Click Apply, then OK. Lower values render in one end of the ramp, higher values in the other.
  6. Add the Rwanda boundary as a vector overlay, then use the Print Layout (Project → New Print Layout) to add a title, legend, scale bar, and north arrow for your report.
Why local rasters: Because the GeoTIFF is stored on your computer, QGIS can re-classify, re-colour and print it freely. A streaming GEE tile is only a picture from the server, so its symbology is fixed — always export to GeoTIFF for any layer you need to style or publish.

rwanda_climate_trends_full.js
// ============================================================
// RWANDA WEATHER & CLIMATE TREND ANALYSIS (2015-2025)
// CHIRPS rainfall + ERA5-Land temperature | annual trends
// Clipped to Rwanda | Charts | Trend maps | Export | Web App
// ============================================================

// --- 0. Study period ---
var startYear = 2015, endYear = 2025;
var years = ee.List.sequence(startYear, endYear);

// --- 1. Rwanda boundary ---
var countries = ee.FeatureCollection('FAO/GAUL_SIMPLIFIED_500m/2015/level0');
var rwanda = countries.filter(ee.Filter.eq('ADM0_NAME', 'Rwanda'));
var aoi = rwanda.geometry();
Map.centerObject(aoi, 8);
Map.addLayer(rwanda, {color: 'white'}, 'Rwanda Boundary');

// --- 2. CHIRPS rainfall -> annual totals ---
var chirps = ee.ImageCollection('UCSB-CHG/CHIRPS/PENTAD')
  .select('precipitation')
  .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01')
  .filterBounds(aoi);

var annualRain = ee.ImageCollection.fromImages(
  years.map(function(y){
    y = ee.Number(y);
    var s = ee.Date.fromYMD(y,1,1), e = s.advance(1,'year');
    return chirps.filterDate(s,e).sum().clip(aoi).rename('rain')
      .set({year:y, 'system:time_start': s.millis()});
  })
);
var rainMean = annualRain.mean().rename('rain_mean');

// --- 3. ERA5-Land temperature -> annual means (C) ---
var era5 = ee.ImageCollection('ECMWF/ERA5_LAND/MONTHLY_AGGR')
  .select('temperature_2m')
  .filterDate(startYear + '-01-01', (endYear + 1) + '-01-01');

var annualTemp = ee.ImageCollection.fromImages(
  years.map(function(y){
    y = ee.Number(y);
    var s = ee.Date.fromYMD(y,1,1), e = s.advance(1,'year');
    return era5.filterDate(s,e).mean().subtract(273.15)
      .clip(aoi).rename('temp')
      .set({year:y, 'system:time_start': s.millis()});
  })
);
var tempMean = annualTemp.mean().rename('temp_mean');

// --- 4. Visualise means ---
var rainVis = {min:800,max:1600,palette:['#ffffcc','#a1dab4','#41b6c4','#2c7fb8','#253494']};
var tempVis = {min:15,max:24,palette:['#2c7bb6','#abd9e9','#ffffbf','#fdae61','#d7191c']};
Map.addLayer(rainMean, rainVis, 'Mean Annual Rainfall');
Map.addLayer(tempMean, tempVis, 'Mean Annual Temp (C)', false);

// --- 5. Rainfall anomaly for a chosen year ---
var targetYear = 2023;
var yearImg = ee.Image(annualRain.filter(ee.Filter.eq('year',targetYear)).first());
var rainAnomaly = yearImg.subtract(rainMean).rename('rain_anom');
var anomVis = {min:-400,max:400,palette:['#8c510a','#d8b365','#f6f6f6','#5ab4ac','#01665e']};
Map.addLayer(rainAnomaly, anomVis, 'Rainfall Anomaly '+targetYear, false);

// --- 6. Per-pixel linear trend (slope) ---
var addYearBand = function(img){
  var yr = ee.Number(img.get('year'));
  return img.addBands(ee.Image.constant(yr).toFloat().rename('year'));
};
var rainTrend = annualRain.map(addYearBand).select(['year','rain'])
  .reduce(ee.Reducer.linearFit()).select('scale').rename('rain_slope').clip(aoi);
var tempTrend = annualTemp.map(addYearBand).select(['year','temp'])
  .reduce(ee.Reducer.linearFit()).select('scale').rename('temp_slope').clip(aoi);
Map.addLayer(rainTrend, {min:-30,max:30,palette:['#8c510a','#f6f6f6','#01665e']}, 'Rainfall Trend (mm/yr)', false);
Map.addLayer(tempTrend, {min:-0.1,max:0.1,palette:['#2c7bb6','#f6f6f6','#d7191c']}, 'Temperature Trend (C/yr)', false);

// --- 7. Time-series charts ---
print(ui.Chart.image.series({imageCollection:annualRain, region:aoi, reducer:ee.Reducer.mean(), scale:5500, xProperty:'year'})
  .setChartType('ColumnChart').setOptions({title:'Mean Annual Rainfall over Rwanda', hAxis:{title:'Year',format:'####'}, vAxis:{title:'mm/year'}, colors:['#2c7fb8'], legend:{position:'none'}}));
print(ui.Chart.image.series({imageCollection:annualTemp, region:aoi, reducer:ee.Reducer.mean(), scale:11000, xProperty:'year'})
  .setChartType('LineChart').setOptions({title:'Mean Annual Temperature over Rwanda', hAxis:{title:'Year',format:'####'}, vAxis:{title:'C'}, colors:['#d7191c'], pointSize:5, legend:{position:'none'}}));

// --- 8. Export layers ---
Export.image.toDrive({image:rainMean.toFloat(), description:'Rwanda_MeanRainfall_2015_2025', folder:'earthengine', fileNamePrefix:'rwanda_rain_mean', region:aoi, scale:5500, crs:'EPSG:32735', maxPixels:1e13});
Export.image.toDrive({image:rainTrend.toFloat(), description:'Rwanda_RainfallTrend_2015_2025', folder:'earthengine', fileNamePrefix:'rwanda_rain_trend', region:aoi, scale:5500, crs:'EPSG:32735', maxPixels:1e13});
Export.image.toDrive({image:tempTrend.toFloat(), description:'Rwanda_TempTrend_2015_2025', folder:'earthengine', fileNamePrefix:'rwanda_temp_trend', region:aoi, scale:11000, crs:'EPSG:32735', maxPixels:1e13});

// --- 9. Web app UI ---
Map.setControlVisibility({layerList:true});
var panel = ui.Panel({style:{width:'330px', padding:'12px'}});
panel.add(ui.Label('Rwanda Climate Trends Explorer', {fontSize:'20px', fontWeight:'bold', color:'#2c7fb8'}));
panel.add(ui.Label('CHIRPS rainfall & ERA5-Land temperature | 2015-2025', {fontSize:'12px', color:'gray'}));
var makeRow = function(c,n){ return ui.Panel([ui.Label('',{backgroundColor:c,padding:'8px',margin:'0 6px 0 0'}), ui.Label(n,{margin:'0',fontSize:'13px'})], ui.Panel.Layout.Flow('horizontal')); };
var legend = ui.Panel({style:{padding:'8px 0 0 0'}});
legend.add(ui.Label('Trend direction', {fontWeight:'bold', fontSize:'13px'}));
legend.add(makeRow('#8c510a','Drying / Cooling'));
legend.add(makeRow('#f6f6f6','Little change'));
legend.add(makeRow('#01665e','Wetting'));
legend.add(makeRow('#d7191c','Warming'));
panel.add(legend);
ui.root.add(panel);

§Data Sources & Limitations

Datasets

  • CHIRPS Pentad — Funk et al. (2015), Climate Hazards Group InfraRed Precipitation with Station data. Earth Engine ID UCSB-CHG/CHIRPS/PENTAD.
  • ERA5-Land Monthly Aggregated — Muñoz-Sabater et al. (2021), Copernicus Climate Change Service / ECMWF. Earth Engine ID ECMWF/ERA5_LAND/MONTHLY_AGGR.
  • FAO GAUL 2015 (level 0) — administrative boundaries, Earth Engine ID FAO/GAUL_SIMPLIFIED_500m/2015/level0.

Known limitations

  • Short record: 11 years is at the lower end for robust climate-trend detection; report trends as indicative.
  • Resolution: ~5.5 km rainfall and ~11 km temperature smooth over local terrain — Rwanda's steep relief means real micro-climates are averaged out.
  • Data type: CHIRPS is a satellite-station blend and ERA5-Land is a reanalysis model, not direct gauge measurements; each carries its own error.
  • No significance test: the linearFit slope has no p-value here. For a stronger claim, add a Mann-Kendall or Sen's slope test.
